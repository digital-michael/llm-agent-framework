---

## Relationship Between Workflows

The **assignment workflow** governs the full lifecycle of an assignment — from intake through close. It defines the phases, gates, and required steps.

The **iterative process** governs what happens *inside* Phase 5 (Implementation). It is the loop that runs until the implementation plan is complete.

Think of the assignment workflow as the outer loop, and the iterative process as the inner loop.
